# Meeting Preparation

## When This Applies
- David mentions preparing for a meeting
- Upcoming 1:1 discussion
- "What should I cover in..." type questions

## Preparation Workflow

### 1. Gather Context
- Check calendar for meeting details (time, attendees, recurring?)
- Search notes for any existing prep or previous meeting notes
- Search memory for recent conversations about this person/topic

### 2. For 1:1 Meetings
Structure preparation around:

**Updates to Share**
- What have I accomplished since last time?
- What's in progress?
- Any wins worth highlighting?

**Items to Discuss**
- Blockers or challenges
- Decisions needing input
- Resources or support needed

**Questions to Ask**
- Feedback on recent work
- Priorities or shifting goals
- Career development (if appropriate)

### 3. For Group Meetings
- What's my role? (Presenting, participating, observing?)
- What decisions need to be made?
- What information should I have ready?

## Output Format
When helping with meeting prep, provide:
- Bullet points, not paragraphs
- Clear sections (Updates / Discussion / Questions)
- Time estimates if meeting is short

## What NOT To Do
- Don't create formal agendas unless asked
- Don't be overly corporate in language
- Don't add unnecessary items to seem thorough
