# Sara natural conversation suite: 40 complete conversation scripts

Use with `SARA_NATURAL_CONVERSATION_EVALUATION_PLAN_2026_09_23.md`.

**352 user turns:** cases 01–36 contain eight each; 37–40 contain sixteen each. Generate and preserve a real Sara reply after every numbered line, with all previous actual replies in history. Sara's replies are intentionally not prewritten: they are the evidence this experiment must produce. This file supplies complete user trajectories and behavioral checks, not transcripts of tests already run.

Development cases: 01, 03, 06, 11, 15, 19, 24, 29. All others are held out. All personal details below are synthetic. The checks are evaluator-only; do not place them or future user lines in Sara's prompt. Do not fake an error merely to reach a repair turn. A request to change style is valid even if the evaluator liked Sara's earlier style.
